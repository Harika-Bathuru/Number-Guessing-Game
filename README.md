# Number-Guessing-Game
A simple Java-based Number Guessing Game built using AWT, JFrame and Swing concepts. The project may look small, but while building it I explored several important Java GUI fundamentals and event-handling concepts.

🚀 Features
Random number generation
User input handling
Hint messages (Too High / Too Low)
Attempt tracking
Interactive GUI
Responsive button actions using event listeners
Simple and clean game logic

🛠 Technologies Used
Java
AWT
Swing
Event Handling
OOP Concepts

📚 What I Learned
While developing this project, I practiced:

Creating GUI windows using Swing
Using AWT components and layouts
Handling button click events
Taking user input dynamically
Updating UI components based on conditions
Working with Java logic and control statements
Improving problem-solving skills through game development
